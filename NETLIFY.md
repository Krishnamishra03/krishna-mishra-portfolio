# Deploying to Netlify

1. Push this repo to GitHub (Lovable → GitHub → Connect).
2. In Netlify: **Add new site → Import an existing project** → pick the repo.
3. Netlify reads `netlify.toml`, so leave the build settings as detected:
   - Build command: `npm run build`
   - Publish directory: `dist`
   - `NITRO_PRESET=netlify` (already set in `netlify.toml`)
4. Deploy.

## Notes
- SSR is handled by a Netlify Function generated by Nitro at build time — no
  `_redirects` file is needed; client-side routes and deep links work as-is.
- Any `VITE_*` environment variables your app uses must be added under
  **Site configuration → Environment variables** in Netlify, since they are
  inlined at build time.
- Server-only secrets (non-`VITE_`) go in the same place; they are read at
  request time inside server functions.
