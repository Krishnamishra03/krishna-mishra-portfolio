# Deploying to Netlify

This project is configured to build for Netlify SSR using Nitro.

## One-click deploy steps

1. **Push to GitHub**
   - In Lovable: click the **+** menu → **GitHub** → **Connect project**.
   - This creates a repo and syncs your code to it.

2. **Import into Netlify**
   - Go to [netlify.com](https://netlify.com) → **Add new site** → **Import an existing project**.
   - Select the GitHub repo you just connected.

3. **Leave build settings as detected**
   Netlify will read `netlify.toml` automatically:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
   - **Node version:** 22
   - **Nitro preset:** `netlify` (set in `vite.config.ts`)

4. **Deploy**
   - Click **Deploy site**.
   - Netlify builds the project, serves static assets from `dist/`, and runs SSR from `.netlify/functions-internal/server/`.

## Environment variables

If your app uses any `VITE_*` variables, add them in Netlify under:
**Site configuration → Environment variables**

These are inlined at build time, so they must be present before the first deploy.

## Notes

- SSR is handled automatically by a Netlify Function generated by Nitro.
- Client-side routes and deep links work out of the box — no `_redirects` file needed.
- The Lovable sandbox always builds for Cloudflare locally, but the production build targets Netlify because of the explicit `nitro: { preset: "netlify" }` in `vite.config.ts`.
